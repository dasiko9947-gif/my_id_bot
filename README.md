# Telegram ID Bot

Бот для определения числового ID пользователей Telegram.

## Возможности
- Показывает ID пользователя при любом сообщении
- Определяет ID из пересланных сообщений
- Определяет ID автора при ответе на сообщение
- Сохраняет ID в SQLite для рассылок
- Поддержка донатов звёздами Telegram

## Установка
1. Клонируйте репозиторий
2. Создайте виртуальное окружение
3. Установите зависимости
4. Создайте файл `.env` с токеном бота

## Команды
- `/start` - приветствие и ваш ID
- `/help` - инструкция
- `/terms` - условия использования
- `/donate` - поддержка проекта
